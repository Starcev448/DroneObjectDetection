# DroneObjectDetection

Проект выполнен в рамках производственной практики.

## Описание

Разработана система сравнительного анализа современных моделей детекции объектов на изображениях с беспилотных летательных аппаратов.

## Используемые модели

- YOLO11
- Faster R-CNN
- RetinaNet
- SSD300
- FCOS

## Используемый датасет

VisDrone

## Возможности

- обучение моделей;
- тестирование;
- оценка качества (mAP50, mAP50-95, Precision, Recall);
- измерение скорости работы (FPS);
- построение сравнительных графиков;
- экспорт результатов в Excel.
